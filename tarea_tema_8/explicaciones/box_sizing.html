Propiedad Box-Sizing

Index

La propiedad box-sizing nos permite indicar cómo se va a calcular el ancho y el alto de una caja:

  • content-box: Cuando se indican los valores de width y height se hace con respecto al content (contenido).
  • border-box: Cuando se indican los valores de width y height se hace con respecto a toda la caja, incluido el padding y el border.

Ejemplo

Ambas cajas tienen declarado un ancho de 300px, un padding de 20px y un borde de 10px:

box-sizing: content-box (Valor por defecto)

El tamaño total en pantalla es mayor porque el padding y el borde se suman por fuera (300px + 40px de padding + 20px de borde = 360px).

box-sizing: border-box

El tamaño total en pantalla se respeta exactamente en 300px, calculando el relleno y el borde hacia adentro.
