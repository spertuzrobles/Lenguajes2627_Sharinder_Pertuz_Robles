Propiedad Overflow

Index

Mediante la propiedad overflow controlamos qué debe hacerse cuando el contenido de una caja desborda su tamaño:

  • visible: Aunque el contenido lo desborde, este se muestra fuera de la caja.
  • hidden: Se oculta lo que no quepa en la caja.
  • scroll: Se generan barras de desplazamiento para poder ver todo el contenido, aunque no sean necesarias.
  • auto: El navegador se encarga de poner barras de scroll si es necesario.

Ejemplos

overflow: visible

Este texto es muy largo y va a desbordar la caja porque el valor visible permite que se muestre fuera de sus límites.

overflow: hidden

Este texto es muy largo y el sobrante quedará completamente oculto ya que la propiedad hidden recorta todo lo que no cabe.

overflow: scroll

Este texto tiene barras de desplazamiento forzadas para ver el contenido excedente en todo momento.

overflow: auto

Este texto es largo y generará barras de desplazamiento automáticas solo si el espacio lo requiere.

En estos ejemplos podemos observar cómo reacciona el contenedor según el valor de overflow que le indiquemos cuando el texto supera el tamaño establecido.
