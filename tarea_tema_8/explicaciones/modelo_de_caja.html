Modelo de caja (Box Model)

Index

En CSS, todo elemento es considerado como una caja rectangular. El Modelo de Caja se compone de cuatro capas:

  • Contenido (Content): El área donde se muestra el texto, imágenes u otros elementos.
  • Relleno (Padding): El espacio libre alrededor del contenido pero dentro del borde.
  • Borde (Border): La línea que rodea al padding y al contenido.
  • Margen (Margin): El espacio libre exterior que separa esta caja de otros elementos contiguos.

En este ejemplo el contenido seria el texto qu esta en blanco dentro de la caja. Contenido es todo lo que mostremos dentro de nuestra "caja".
