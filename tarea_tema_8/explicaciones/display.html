Propiedad Display

Index

La propiedad display nos permite modificar el comportamiento y el tipo de caja de los elementos:

  • block: Se crea la caja como un bloque. Ocupan todo el ancho si no se establece uno y se adaptan al alto del contenido si tampoco se establece uno. Comienzan en una nueva linea.
  • inline: No inician una nueva linea, ocupan el ancho necesario para su contenido y no les afecta el width o el height.
  • inline-block: Combina características de línea y bloque.
  • none: Se oculta el elemento por completo.
  • flex: Es un diseño flexible que distribuye el espacio entre sus hijos.
